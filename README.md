## 🚨 The Problem

People increasingly interact with strangers, businesses, recruiters, sellers, and online contacts without knowing how much publicly searchable information is associated with an identity.

A simple name, phone number, email address, or profile image can appear across multiple websites and platforms.

The problem is not simply finding information.

The real challenge is determining:

- Which search results may refer to the same person?
- Which results may belong to different people with similar identities?
- Are there conflicting professional or location signals?
- Does the same image appear across unrelated websites?
- Is a contact detail associated with multiple names?
- Which search results are meaningful evidence and which are low-quality or automatically generated pages?
- What should a person verify before trusting an online identity?

Manually performing these checks can require searching multiple platforms, opening dozens of results, and comparing information across sources.

**DigitalTrace automates this initial public-footprint investigation and presents the findings in a simple, explainable format.**

---

# 💡 What is DigitalTrace?

**DigitalTrace** is an AI-assisted digital identity verification and scam-awareness tool that analyzes publicly searchable information using live web search.

Users can check:

- 👤 **Name**
- 📧 **Email**
- 📱 **Phone number**
- 🖼️ **Profile/image**

The system retrieves public search results using **SerpApi**, converts those results into structured evidence, identifies potentially different identity clusters, applies a deterministic evidence-based scoring system, and uses **Google Gemini** to explain the findings in plain language.

The goal is to help users understand their **digital exposure and identity ambiguity** before making decisions based on an online identity.

---

# 🎯 Core Idea

DigitalTrace follows this principle:

> **Search evidence should be separated from AI interpretation.**

The risk/exposure score is **not generated by Gemini**.

Instead:

1. SerpApi retrieves public search evidence.
2. The Evidence Engine structures the results.
3. Identity Clustering groups results into likely identities.
4. The deterministic Risk Scorer detects predefined signals.
5. The score is calculated using fixed rules and weights.
6. Gemini explains the already-calculated assessment.
7. Streamlit presents the findings and supporting evidence.
8. Users can download a PDF report.

This makes the system more **transparent, reproducible, and explainable**.
